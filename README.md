# Flow — приложение для Android

Актуальная версия: **0.2.110** от 01.10.2026. Что нового: Экраны аккуратнее: панели до низа, заголовки плотнее; подсказка «Работа в фоне» стала ненавязчивой

## Установка

1. [Скачать Flow-latest.apk](https://github.com/Cap1talist/Flow-android-releases/raw/main/Flow-latest.apk) (49 МБ).
2. Открыть файл. Если телефон спросит про установку из неизвестных источников — разрешить для браузера или «Файлов»
   (на Huawei: Настройки → Безопасность → Установка приложений из внешних источников).
3. Запустить Flow, вставить ссылку подписки из личного кабинета и нажать знак.

Android 7.0 и новее, только arm64 (все телефоны последних лет). Сервисы Google не нужны, на Huawei работает.

## Обновления

Приложение само проверяет этот репозиторий (`version.json`) и показывает плашку «Доступна версия». Установка
поверх сохраняет подписку и настройки. Проверить вручную: Настройки → «Проверить обновление».
